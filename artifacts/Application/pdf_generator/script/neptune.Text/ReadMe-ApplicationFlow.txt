Application Flow: Sales Orders Application

1. Home Screen / Dashboard
	Overview: 
    •   Displays a pie chart of orders categorized by status (Approved, Pending, Rejected).
	Key Actions:
	•	Filter orders using segmented buttons by status (Approved, Pending, Rejected).
	•	Search and filter orders using keywords or specific criteria.
	Additional Features:
	•	Download or print the pie chart using integrated analytics (Highcharts).

2. Order Details Screen
	How to Access: 
    •   Click on a specific sales order from the filtered list.
	Displayed Information:
	•	Detailed data for the selected order.
	•	Current status (Approved, Pending, Rejected).
	Key Actions:
	•	Approve/Reject Order: Toggle the status of the sales order.
	•	Comments Section: Add comments related to the order for better communication and tracking.
	•	Signature Pad: Sign the sales order as part of the approval/rejection process.
	•	Generate PDF: Preview the sales order in a dynamically generated PDF format.

3. Create Sales Order Screen
	How to Access: 
    •	Click on the “+Add” button located in the bottom-right corner of the home screen.
	•	Displayed Fields:
	•	Input form to enter relevant sales order details (e.g., customer info, product details, pricing, etc.).
	Key Actions:
	•	Fill out the form and click Create.
	•	Notification displayed: “Sales Order Created Successfully.”
	•	Redirect back to the home screen to view the new sales order in the list.

4. PDF Management
	How to Access:
    •   From the Order Details screen, click View Sales Order.
	Key Features:
	•	Dynamically generate a PDF based on the order data.
	•	Preview the PDF within the application.
	•	Download the PDF for external use or printing.
    •	Access the generated PDFs from the PDF Archive tool.
